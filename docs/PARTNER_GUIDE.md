# Инструкция для партнёра

## Куда писать
Telegram-бот: **@bot_atelier_open_code_bot**

## Как поставить задачу
1. Нажмите внизу кнопку **«🆕 Новая сессия редактирования»**.
2. Одним сообщением опишите, что нужно сделать: что не так, на каком экране, что должно быть в итоге.
3. При необходимости прикрепите **скриншот** (можно несколько).
4. Отправьте — бот передаст задачу агенту.

## Если нужно доработать прежнюю задачу
Нажмите **«📂 Выбрать сессию»** и выберите нужную сессию из списка — агент продолжит с тем же контекстом.
(Новую, не связанную задачу лучше начинать через «🆕 Новая сессия редактирования».)

## Что можно присылать
- текстовое описание правки;
- скриншоты/фото;
- уточнения по ходу работы.

## Если агент задаёт вопрос
Бот покажет вопрос с кнопками вариантов — просто нажмите нужный или ответьте текстом.

## Чего делать не нужно
- знать код, SSH или сервер — всё делает агент;
- выбирать проект — он уже настроен (**Экосистема Бот-ателье**);
- что-то запускать вручную.

## Кнопки внизу
- **«🆕 Новая сессия редактирования»** — начать новую задачу;
- **«📂 Выбрать сессию»** — продолжить/доработать ранее начатую задачу;
- **«⚙️ Настройки»** — при необходимости: проект, модель, список команд.

## Результат
Готовую правку проверяет владелец. Если потребуется — вернётся с уточнением.
